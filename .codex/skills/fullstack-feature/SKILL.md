# Skill: fullstack-feature

## Purpose

Implémenter une feature CyberManager de bout en bout.

## When to use

Utiliser cette skill lorsqu'une feature nécessite :
- backend + frontend
- nouveaux cas d’usage
- nouvelle API
- nouvel écran Angular

## Required inputs

- le fichier de feature
- AGENTS.md
- les bounded contexts impliqués

## Steps

1. Lire la feature.
2. Identifier les bounded contexts.
3. Implémenter le backend :
    - domain
    - application
    - infrastructure
    - api
4. Implémenter le frontend :
    - pages
    - services
    - modèles
    - composants
5. Connecter le frontend au backend.
6. Ajouter les tests utiles.
7. Vérifier le respect DDD et la cohérence API/UI.

## Output format

Toujours fournir :
- découpage backend
- découpage frontend
- endpoints exposés
- écrans impactés
- fichiers créés / modifiés
- risques ou points ouverts
